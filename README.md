`entry.png` is a 1024 × 1024 newspaper-style page with 46 stories across
9 regions — North America, Latin America, Europe, Middle East, Africa,
South Asia, East Asia, Southeast Asia, Oceania — plus the day's markets.
The top story: Houthi strikes on a Saudi oil refinery and the Riyadh
financial district. Sources checked for the date: Reuters, AP, AFP, BBC,
SCMP, NHK, Japan Times, Al Jazeera, Le Monde — all stories dated
25 November 2026.

## Run it

```sh

```

Writes `entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when set).
Deterministic: two runs produce byte-identical output. No network.
